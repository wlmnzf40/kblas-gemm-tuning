# 性能基线测试结果

## 测试环境

- **平台**：鲲鹏 aarch64 / openEuler 20.03-LTS-SP3
- **CPU**：Kunpeng 920 (armv8.2-a)
- **KML**：boostkit-kml-1.7.0（OMP 版 libkblas）
- **TF**：2.17.0（TF-Serving）
- **编译器**：GCC 12.3.1 / Bazel 7.4.1
- **编译配置**：`--config=kml_kblas`（`-O3 -march=armv8.2-a -fopenmp`）

## 性能分析

1. **KBLAS 在超大矩阵上有明显优势**：2048x2048 达到 2.18x 加速
2. **中等矩阵（64~256 范围）**：KBLAS 在部分形状上有 1.5~2x 加速
3. **小矩阵性能显著下降**：128x128 和 256x256 上 KBLAS 远慢于 Eigen
4. **特定形状异常**：部分形状（如 `59x128x64`）KBLAS GFLOPS 极低（0.7），可能存在初始化开销或线程调度问题

## 结论

KBLAS 适合大规模矩阵乘法场景（2048+），在推荐系统中的中等尺寸矩阵上部分有效。
小矩阵场景下 Eigen 仍是更好的选择。建议根据实际矩阵尺寸动态选择 backend。

> **说明**：以上数据为特定硬件环境下的基线测试结果，实际性能受 CPU 型号、内存带宽、
> 系统负载等影响，仅供参考。建议在目标环境重新跑 `compare_backends.sh` 获取实测数据。
